# Portal Berita Kabar_PBSIUMUS

Portal Berita Kabar_PBSIUMUS adalah platform web berita interaktif dan modern yang dirancang khusus untuk civitas akademika dan masyarakat umum, terintegrasi langsung dengan database **Firebase Firestore** untuk pengelolaan konten secara *real-time*.

## 🚀 Fitur Utama
* **Berita Utama & Kategori**: Navigasi kategori berita yang lengkap (PBSI_UMUS, Politik, Ekonomi, Olahraga, Pendidikan, dll).
* **Mode Admin & Publik**: 
  * Akses Admin tersembunyi (klik logo utama 5 kali) untuk menambah, mengedit, dan menghapus berita secara online.
  * Fitur kirim draf berita bagi pengunjung umum melalui email.
* **Interaksi Pengguna**: Fitur "Suka" (*Like*) dan kolom komentar dinamis pada setiap artikel berita.
* **Pencarian Cepat**: Kolom pencarian berita secara *real-time*.
* **Media Fleksibel**: Mendukung unggahan gambar maupun video langsung dari perangkat.

## 🛠️ Teknologi yang Digunakan
* **Frontend**: HTML5, CSS3, JavaScript (ES6 Modules)
* **Styling**: Google Fonts (Poppins), FontAwesome Icons
* **Database & Backend**: Firebase Firestore (v12)
* **Hosting**: GitHub Pages / Vercel
